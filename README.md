# Explore-Hub

Welcome to the Explore-Hub project! This repository contains the source code for a modern and responsive travel website.

## Features

- **Responsive Design**: Optimized for all devices.
- **Interactive UI**: Engaging user interface with smooth animations.
- **Cross-Browser Compatibility**: Works seamlessly across major browsers.

## Technologies Used

- **HTML5**: For structuring the content.
- **CSS3**: For styling and layout.

## Live Demo

Check out the live version of the website here: [Explore-Hub Live](https://your-hosting-url.com)

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/dyavanpallyrohankumar/Explore-Hub.git
    ```
2. Navigate to the project directory:
    ```bash
    cd Explore-Hub
    ```
3. Open `index.html` in your browser to view the website.
